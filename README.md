# WeakC4-Webpage
This webpage documents a minimal weak solution to Connect 4. The graph shown is an entire weak solution, which can be memorized in order to guarantee perfect play as player 1.
 
See the graph [here](https://2swap.github.io/WeakC4/), and some explanation [here](https://2swap.github.io/WeakC4/explanation).
![sample](sample.png)

Steady-state diagrams that shrink the graph are welcome; see [CONTRIBUTING.md](CONTRIBUTING.md). New diagrams are exhaustively verified automatically, and the representations are rendered from `solution/steady_states.json` and `solution/branches.json` after merge.
